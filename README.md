========================================================
   MIM89 PRINT BRIDGE  -  تعليمات التشغيل
========================================================

المشكلة السابقة كانت: اسم ملف بايثون لم يطابق ما يبحث عنه
ملف التشغيل، فكانت النافذة تُغلق فوراً بدون رسالة.

هذه النسخة محصّنة: تجد الملف تلقائياً، وتسجّل كل ما يحدث
في ملف نصي اسمه bridge_log.txt حتى لو انغلقت النافذة.

--------------------------------------------------------
الخطوات:
--------------------------------------------------------

1) احذف كل الملفات القديمة من مجلد MIM89-Printer
   وضع بدلها الملفات الثلاثة الجديدة:
       INSTALL_LIBS.bat
       START_BRIDGE.bat
       bridge.py

2) اضغط مرتين على:  INSTALL_LIBS.bat
   انتظر حتى ينتهي، ثم اقرأ آخر ثلاثة أسطر:
       [OK] Pillow      : installed
       [OK] Arabic      : installed
       [OK] Bidi        : installed

   اذا ظهرت [FAIL] لأي واحد منها = المكتبة لم تُثبّت
   (تحقق من الانترنت وأعد المحاولة)

3) اضغط مرتين على:  START_BRIDGE.bat
   يجب أن تبقى النافذة مفتوحة وتعرض:
       Bridge is now RUNNING at:
          http://localhost:8899

4) اترك النافذة مفتوحة طوال الدوام.

--------------------------------------------------------
اذا انغلقت النافذة فجأة:
--------------------------------------------------------

افتح ملف  bridge_log.txt  الموجود في نفس المجلد
(بالمفكرة Notepad) وأرسل صورة لمحتواه.
هذا الملف يسجّل السبب الحقيقي بالضبط.

--------------------------------------------------------
عناوين الطابعات الحالية:
--------------------------------------------------------
   الكاشير : 192.168.0.218
   المطبخ  : 192.168.0.200

لتغييرها: افتح bridge.py بالمفكرة وعدّل قسم PRINTERS
في أعلى الملف، ثم أعد تشغيل الجسر.

--------------------------------------------------------
مهم جداً عن الكاشير:
--------------------------------------------------------
الطباعة المباشرة تعمل فقط اذا فتحت صفحة الكاشير من
نفس الكمبيوتر الذي يشغّل الجسر، والعنوان يكون:
    http://localhost:8899

اذا فتحت الكاشير من جهاز آخر (آيباد مثلاً) فالمتصفح
سيحجب الاتصال لأسباب أمنية، وستحتاج أزرار الطباعة
اليدوية.
